# Streamly — Video-Sharing Platform

Streamly is a full-stack video-sharing platform inspired by modern video streaming applications. This project is being developed to strengthen my full-stack development skills and understand how real-world video platforms work.

## Tech Stack

- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Tools:** Git, GitHub, VS Code

## Planned Features

- User registration and login
- User profiles and channel management
- Video upload and management
- Video browsing and playback
- Like and comment functionality
- Subscribe and unsubscribe functionality
- Search and video discovery

## Project Goals

- Build a complete full-stack application
- Practice REST API development and database design
- Implement authentication and authorization
- Understand frontend-backend integration
- Follow clean code and project structure practices

🚧 In Development

Features and technologies will be updated as development progresses.
